# Catalog expansion — 2026-09-06

## Admission rule

This is internal editorial evidence, not player-facing copy. Admit Steam Windows releases with `platforms.mac: false` and a matching CodeWeavers compatibility entry whose current **Mac** rating is Runs Great/Well. Ratings are observations for the named CrossOver release, not guarantees for every machine, later patch, multiplayer mode, or DLC. CodeWeavers hosts community ratings and tips; these are not a vendor support warranty. Do not convert Windows system requirements into Mac minimum requirements.

Steam API requests below were retrieved directly on 2026-09-06 with `l=english&cc=us`. Store age gates were handled by reading the public API, not fabricating birth dates. Some CodeWeavers overviews returned HTTP 403 to direct open; those records are explicitly identified as search-index observations rather than live page reads.
