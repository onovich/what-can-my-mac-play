# What Can My Mac Play Context

This glossary defines the compatibility concepts used to turn traceable observations into environment-specific Mac gaming guidance.

## Catalog

**Game**:
A canonical game product. A game can have multiple names and editions, but it is not itself a compatibility result.
_Avoid_: Title record, app

**Source**:
An upstream publisher, service, or community that makes compatibility-related information available under a known usage policy.
_Avoid_: Provider, website

## Compatibility evidence

**Evidence**:
A dated, traceable observation from one Source that supports one or more compatibility claims about a Game. Evidence preserves provenance and must not be presented as independent testing by this project.
_Avoid_: Proof, fact, result

**Environment**:
The known Mac hardware, operating system, runner, and graphics characteristics in which compatibility was observed or assessed. Unreported characteristics remain explicitly unknown rather than inferred.
_Avoid_: Device, setup, profile

**Compatibility Report**:
A structured interpretation of Evidence for one Game in one Environment at a particular time. It records distinct install, launch, gameplay, completion, and feature outcomes.
_Avoid_: Review, rating, test

**Compatibility Score**:
A 0–100 estimate of how well a Game is expected to run in a target Environment, based only on available Compatibility Reports.
_Avoid_: Confidence, rating

**Confidence Score**:
A separate 0–100 estimate of how trustworthy a Compatibility Score is, based on evidence quantity, quality, freshness, agreement, and relevance to the target Environment.
_Avoid_: Compatibility, certainty

**Unknown**:
The state used when available Evidence cannot support a compatibility outcome. Unknown is not evidence that a Game is unplayable.
_Avoid_: Unsupported, unplayable

**Unplayable**:
A supported outcome showing that a Game cannot complete a required compatibility stage in the stated Environment.
_Avoid_: Unknown, unsupported
